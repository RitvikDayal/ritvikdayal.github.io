01 Doxel · 2026 Latest

BIM review and markup, in a browser tab

Reviewing a model used to mean Navisworks or AutoCAD on a workstation, a paid seat for every reviewer, and a file shipped around by hand. This replaces all of that with a link: open the model in a browser, walk it in 3D, draw straight over the floor plan, and leave the markup where the next person will find it.

The 3D model, the 2D floor plan and site imagery share one review surface, so a comment can point at the geometry instead of describing it. People who never had a desktop licence can now take part in the review, and the model never has to leave the platform to get looked at.

04 GeeksforGeeks · 2022

Code-execution architecture around an existing compiler

The obvious answer to running learners' code was to build a compiler service. We didn't. I designed the system around the compiler that already existed — an IDE-like execution server that wraps it in a Docker sandbox, isolates multi-language runs, and treats the toolchain as a dependency rather than a product.

The architecture was the win: 30–40% less cost and complexity than building and maintaining our own, 20% less compute at peak traffic, and Python and Go supported on day one instead of one language at a time.
